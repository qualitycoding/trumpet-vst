Harrison 2015 eq.(10a): y'' + sigma y' + w0^2 y = Sr dp / mu_r (y measured from equilibrium H); (10c) um = w [y+H]+ sqrt(2|dp|/rho) sign(dp); (10d) ur = Sr dy/dt (lip-motion flow); (10e) S(0) v(0,t) = um + ur. Note sigma = w0/Q, so Q = w0/5 (very high Q, e.g. Q ~ 250 at 200 Hz) - different damping convention from the Velut/Freour family. Equivalent mu = Mr/Sr = 3.68 kg/m^2.
