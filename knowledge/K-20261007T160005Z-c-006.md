Compiler: clang or g++.
juce_audio_devices: libasound2-dev; libjack-jackd2-dev (unless JUCE_JACK=0)
juce_audio_processors: ladspa-sdk (unless JUCE_PLUGINHOST_LADSPA=0)
juce_core: libcurl4-openssl-dev (unless JUCE_USE_CURL=0)
juce_graphics: libfontconfig1-dev (unless JUCE_USE_FONTCONFIG=0); libfreetype-dev (unless JUCE_USE_FREETYPE=0; libfreetype6-dev as fallback name)
juce_gui_basics: libx11-dev libxcomposite-dev libxcursor-dev libxext-dev libxinerama-dev libxrandr-dev libxrender-dev libxi-dev (each Xcursor/Xinerama/Xrandr/Xrender/Xinput unless the matching JUCE_USE_X*=0)
juce_gui_extra: libwebkit2gtk-4.1-dev (unless JUCE_WEB_BROWSER=0; libwebkit2gtk-4.0-dev on older systems)
juce_opengl: libglu1-mesa-dev mesa-common-dev libegl-dev
Full command: sudo apt update && sudo apt install libasound2-dev libjack-jackd2-dev ladspa-sdk libcurl4-openssl-dev libfreetype-dev libfontconfig1-dev libx11-dev libxcomposite-dev libxcursor-dev libxext-dev libxinerama-dev libxrandr-dev libxrender-dev libxi-dev libwebkit2gtk-4.1-dev libglu1-mesa-dev mesa-common-dev libegl-dev
New vs older JUCE: libegl-dev is required because JUCE 9 uses EGL rather than GLX for OpenGL contexts on Linux (BREAKING_CHANGES.md, Version 9.0.0, 'JUCE now uses EGL'). Doc states it was tested on Ubuntu 16.04-20.04 and that libfreetype-dev/libfontconfig1-dev are available on Ubuntu 22/24. A plugin that sets JUCE_WEB_BROWSER=0 (NEEDS_WEB_BROWSER defaults to not linking WebKit per CMake API.md line 427) can drop libwebkit2gtk; if not using juce_opengl, GL packages can be dropped.
