Freour eq.(1): y'' + (wl/Ql) y' + wl^2 (y - y0) = (p0 - p)/mu_l. Eq.(2): u = sqrt(2|p0-p|/rho) * b * sign(p0-p) * theta(y), theta(y) = (|y|+y)/2 (forces u=0 when y<0, no contact model). Eq.(3) same pole-residue impedance; eq.(5) pk' = Zc Ck u + sk pk; eq.(6) p = 2 sum Re(pk). 11-12 modes, measured 20 Hz-2 kHz, frequency corrected to 27 C. Dimensionless scaling eq.(9): x = y/y0, PM = mu_l wl^2 y0, gamma = p0/PM, zeta = Zc b y0 sqrt(2/(rho PM)). Freour 2022 constrained continuation (Table 3, p. 11) gives an alternative identified set: Ql = 5.25, mu_l = 2.46 kg/m^2, y0 = 0.078 mm, b = 12.78 mm, fl = 414 Hz (LSA) for Bb4; along branch 2.9 < Ql < 5 and 0.04 < zeta < 0.1 for p0 up to ~3 kPa. Freour 2020 Table 1: sweet-spot fl across 8 high-end Bb trumpets = 376.9-385.1 Hz (mean 380.47, std 2.77) for f4 = 462.5-467.6 Hz.
