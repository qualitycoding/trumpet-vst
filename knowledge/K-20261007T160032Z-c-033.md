Eq.(1): d2h/dt2 + (wl/Ql) dh/dt + wl^2 (h - h0) = (1/mu)(pb - p(t)); wl = 2 pi fl; mu = lip surface-mass equivalent (kg/m^2). Eq.(2) Z = P/U. Eq.(3) Z(w) = Zc * sum_{n=1..N} [Cn/(jw - sn) + Cn*/(jw - sn*)], Zc = rho c / S with S the input cross-section at the mouthpiece rim. Eq.(4) dpn/dt = Zc Cn u(t) + sn pn, p(t) = 2 sum_n Re(pn). Eq.(5) u(t) = sqrt(2/rho) * W * h(t) * sqrt(pb - p(t)), rho = 1.19 kg/m^3 at 20 C, W = lip channel width. Eqs.(6)-(8) state-space form X = [h, dh/dt, {pn}]. Jet assumed laminar in lip channel, turbulent in mouthpiece, no pressure recovery. Mouth pressure pb treated as constant (vocal tract ignored). Velut uses a trombone (Courtois T149) with 18-mode fit, not a trumpet. Practical implementation note (from Freour 2020 eq. 2 and Doc 2023 eq. 4): use u = b*sqrt(2|p0-p|/rho)*sign(p0-p)*max(h,0) to handle reverse flow and lip closure.
