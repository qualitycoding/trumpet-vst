On Linux, creating a Component/AudioProcessorEditor that is not added to the desktop should not need an X connection, but anything touching Desktop/ComponentPeer/Displays (e.g. addToDesktop, screen metrics, some LookAndFeel/Typeface paths) opens an X display; using `xvfb-run -a ctest` (xvfb is preinstalled on ubuntu-24.04 per runner-images Ubuntu2404-Readme.md) is the safe approach. I did not execute a test to confirm which calls need X. pluginval offers --skip-gui-tests for headless CI (v1.0.4 CommandLine.cpp help text).
