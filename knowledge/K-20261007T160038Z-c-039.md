fl ranges giving each regime (Velut Table-2 params, trombone): [30,63] Hz regime 1, [72,123] regime 2, [124,179], [180,234], [235,288], [289,352], [353,404], [405,460] Hz regimes 3-8; equilibrium unconditionally stable for 64-71 Hz. Within each regime fthresh rises monotonically with fl (pitch bending). pthresh(fl) is U-shaped; pthresh rises faster for fl above fl_opt than below (bending down easier). popt,n spans 500 Pa - 15.3 kPa over the regimes. Example: fl = 90 Hz, pthresh = 1222 Pa, fthresh = 116 Hz, steady state 126 Hz (+143 cents) at pb = 1234 Pa; at pb = 3 kPa fosc = 130.5 Hz vs 120.8 Hz from LSA (8% higher). Steady-state frequency therefore drifts sharp with pb in this model - plan for intonation compensation.
