auval is Apple's /usr/bin/auval, shipped with macOS (AudioToolbox) rather than installed by the image scripts, so it is expected to exist on any macOS GitHub runner; however this is an inference, not verified, and AU validation on a headless runner may need the component registered (copy to ~/Library/Audio/Plug-Ins/Components) and the audio component registry refreshed. Recommend a `which auval; auval -h` smoke step in the first CI run. GitHub code search API returned HTTP 500 so a repo-wide grep was not possible; I grepped the git tree paths and readmes only. macOS runner readme lists an 'install-audiodevice.sh' script (audio device tooling), unrelated to auval.
