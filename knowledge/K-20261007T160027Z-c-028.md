Doc comment warns to create/delete these on the message thread. Typical test main(): `juce::ScopedJuceInitialiser_GUI init;` then run Catch2 session (or a custom main in Catch2 with a test-listener). MessageManager::runDispatchLoopUntil(ms) (juce_MessageManager.h:180, only if JUCE_MODAL_LOOPS_PERMITTED) can be used to pump async/timer messages in tests; MessageManager::setCurrentThreadAsMessageThread() (juce_MessageManager.h:274) designates the test thread as the message thread.
